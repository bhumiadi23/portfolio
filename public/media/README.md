# 📁 Media Files — Place Your Files Here

## Photos
Place Annuva's photos in: `public/media/photos/`

```
annuva-01.jpg   ← Used in Story Timeline (memory 1) + Photo Gallery
annuva-02.jpg   ← Used in Story Timeline (memory 2) + Photo Gallery
annuva-03.jpg   ← Used in Story Timeline (memory 3) + Photo Gallery
```

The existing photos in `public/photos/` (photo1.png, photo2.jpg, photo3.png, photo4.png)
are also automatically included in the gallery.

## Videos
Place videos in: `public/media/videos/`

```
memory-01.mp4   ← Video Gallery (first video)
memory-02.mp4   ← Video Gallery (second video)
miss-me.mp4     ← "Watch When You Miss Me" section
final.mp4       ← Final cinematic video (emotional climax)
```

## Music
Place your song in: `public/media/music/`

```
our-song.mp3    ← Plays in "Our Song" section + mini player
```

## Voice Message
Place your voice recording in: `public/media/voice/`

```
message.mp3     ← Plays in "Voice Message" section
```

---

## ✏️ Personalization
Edit `src/data/siteConfig.js` to update:
- Birthday date
- Secret passcode
- Memory descriptions
- Reasons list
- Love letter content
- All messages

The site works perfectly even if media files are missing — it shows beautiful placeholders.
